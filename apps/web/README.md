# Веб-приложение

Публичные страницы описывают TripleCode и показывают установщики из манифеста релизов IDE. Открытые маршруты входа и регистрации ведут в личный кабинет. В кабинете пользователь управляет профилем и подпиской, смотрит лимиты и статистику AI.

Веб-приложение использует Next.js App Router, React и Tailwind CSS.
Компоненты shadcn/ui находятся в `components/ui`, конфигурация — в
`components.json`. Основные маршруты — `/`, `/login` и `/account`.
Формы входа отправляются обычными POST-запросами в Route Handlers. Каждый
запрос кода получает собственную короткоживущую cookie, поэтому формы в
разных вкладках сохраняют свои адреса. Логика обращения к Supabase осталась в
`apps/api`. Перед показом профиля сервер проверяет пользователя через Auth API.

Главная, экран входа, подтверждение кода и профиль используют дизайн
из предоставленного экспорта TripleCode. Демонстрация на главной
позволяет переключать «Вопрос», «План» и «Ревью», имитировать проверку
патча и выбирать файлы для принятия. Цветовая тема сохраняется в браузере.
