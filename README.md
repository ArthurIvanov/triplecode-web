# TripleCode Web

Веб-платформа TripleCode. Репозиторий IDE находится рядом, в `../triplecode`.

| Каталог | Назначение |
| --- | --- |
| [apps/web](apps/web/README.md) | Публичный сайт, загрузка IDE, вход и личный кабинет |
| [apps/api](apps/api/README.md) | Аккаунты, права на AI, подписки, лимиты и аналитика |
| [packages/contracts](packages/contracts/README.md) | Версионированные контракты между IDE, веб-приложением и API |

Публичный сайт и кабинет входят в одно веб-приложение. API можно выпускать отдельно. Страница загрузки читает манифест, который публикует CI репозитория IDE.

## Первый веб-сценарий

Главная → вход или регистрация по email → код из письма → профиль → выход.
Роль ведущего инженера охватывает `apps/web` и `apps/api`. Критерии приёмки
включают успешное подтверждение email, повторный вход с тем же адресом,
повторную отправку кода и серверную проверку сессии перед показом профиля.

### Запуск

Нужен Node.js 22+. Главную можно открыть сразу через `npm run dev` и
[localhost:3000](http://localhost:3000). Для регистрации поднимите Supabase
по [инструкции API](apps/api/README.md), скопируйте `.env.example` в `.env`
и укажите адрес API и publishable key (или локальный anon key). Перезапустите
веб-сервер после правки конфигурации.

`npm test` проверяет HTTP-сценарий с тестовой заменой Supabase Auth. Для
приёмки с реальным Auth откройте форму входа, запросите код, проверьте письмо в
[Mailpit](http://127.0.0.1:54324), введите код и откройте профиль. После выхода
повторите вход с тем же email. Проверьте также неверный код, повторную отправку
и перенаправление с `/account` в браузере без сессии.
